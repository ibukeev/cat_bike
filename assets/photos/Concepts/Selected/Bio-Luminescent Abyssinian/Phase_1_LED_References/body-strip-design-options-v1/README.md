# Phase 1 body-strip design options v1

Open `00-comparison-sheet.jpg` for the four-up review.

| Option | Design language | Fabrication implication |
| --- | --- | --- |
| 1. Minimal Feline Silhouette | Belly curve, arched haunch, basket underlight | Easiest; mostly continuous runs on existing tubes |
| 2. Bioluminescent Dashes | Broken organic markings with two magenta accents | More soldered jumpers and sealed strip ends |
| 3. Feline Ribcage | Rear illuminated spine and ribs | Requires removable backing bars between rack members |
| 4. Geometric Facet Echo | Angular strokes that echo the polygonal head | Most fabrication, connectors, and backing pieces |

These are visual studies, not cut-length drawings. No option is approved until the user selects a direction. Fork, wheel, tire, rotor, chain, crank, steering, and moving-component lighting is intentionally excluded.

Generation mode: built-in `image_gen` edits of the real side-profile photograph. Exact prompt sequence is recorded in `generation-prompts.md`.
