# Lower-right complete opaque print release V4

Use V4 only. V1 through V3 are rejected or withheld and remain unchanged as evidence.

V4 contains exactly one opaque STL file. It includes all 35 accepted members of OPAQUE_RIGHT_LOWER_OWNERS, including the over-nose components, plus the approved opaque connector tabs and the approved right ledge with the exact user extension. Three translucent mating parts remain separate STL files.

The accepted opaque source is intrinsically multi-shell; the original right-lower STL was also multi-part. V4 preserves those shells in one file without a destructive global boolean and without inventing bridges. The combined opaque STL reloaded with 34 connected mesh shells; PrusaSlicer reports manifold=yes and number_of_parts=36.

The negative-X translucent plank remains removed and the rejected zero-area Face6 remains absent. No 3MF, G-code, printer profile, slicing, or print orientation is included.
