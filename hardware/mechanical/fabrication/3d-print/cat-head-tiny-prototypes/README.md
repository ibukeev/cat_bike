# Tiny cat-head prototypes

Both 100 mm versions are retained as useful design milestones.

| Prototype | Files |
| --- | --- |
| [Single shell](single-shell-100mm/README.md) | One hollow shell, Blender model, STL/OBJ, validation, previews, and two saved print jobs. |
| [Modular assembly](modular-100mm/) | Twenty separate shell, glow-insert, and eye-module parts, a Blender assembly, and three slicer projects. |

The modular entry links to the original Gate 7 package inside the large-head
tree. Its files and dependencies were left in place for the separate large-head
review. [Assembly and regeneration notes](../cat-head-full-size-v1/GATE7_SMALL_TEST_PRINT.md)
describe the seven shell parts, seven glow inserts, and six eye-module parts.

The larger head printed for Burning Man is documented separately in
[the midsize package](../cat-head-midsize-bm-2026/README.md).
