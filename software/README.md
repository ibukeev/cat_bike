# Software

Use this area for Pixelblaze patterns and helper scripts.

- `pixelblaze-patterns/` - pattern source, exports, and notes about palette, segment mapping, and controls.
- `tools/` - scripts for LED mapping, pattern export/import, validation, or documentation generation.

The 330 mm head-local pixel map and development patterns are under
`pixelblaze-patterns/cat-head/`.

Keep hardware-specific constants documented near the pattern or tool that uses them.
