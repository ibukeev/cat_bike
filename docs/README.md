# Documentation

Use this area for build instructions, design decisions, safety notes, and field notes.

- `assembly/` - step-by-step installation and maintenance instructions.
- `bom/` - parts lists, vendor links, quantities, and alternates.
- `safety/` - power limits, fusing, waterproofing, strain relief, and Burning Man readiness checks.
- `notes/` - rough notes, measurements, and decision records.
