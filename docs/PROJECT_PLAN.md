# Cat Bike LED Installation Project Plan

## Priority Definitions

- `P0`: Blocking work needed to make the bike rideable, safe, and buildable.
- `P1`: Important work for the Bio-Luminescent Abyssinian identity and playa-ready experience.
- `P2`: Enhancements, showpiece upgrades, polish, and later-phase improvements.

| Workstream | Task | Priority | Task Details | Artefacts | Status |
|---|---|---:|---|---|---|
| Project Definition | Define final bike goals | P0 | Use the Bio-Luminescent Abyssinian concept as the current visual direction. The bike must be rideable and safe day/night, durable against dust/moisture/vibration, iterative, easy to disassemble after Burning Man, and extendable later. | [Concept brief](design/bio-luminescent-abyssinian-concept.md) | Done |
| Project Definition | Define build phases | P0 | Split the project into electrical and independent lighting foundation, cat head, tail, body panels with integrated LEDs, and showpiece upgrades so each phase adds standalone value. | [Concept brief](design/bio-luminescent-abyssinian-concept.md) | Done |
| Visual Design | Document Bio-Luminescent Abyssinian concept | P1 | Capture the keeper elements: gold frame base, faceted copper/rose-gold cat head, cyan/aqua/magenta glow, fiber-optic whiskers, illuminated tail, body glow, and optional wheel effects. | [Concept brief](design/bio-luminescent-abyssinian-concept.md) | In Progress |
| Visual Design | Photograph bike for layout planning | P0 | Capture side, front, rear, and top views for annotated LED placement diagrams. | [LED zone plan](design/led-zone-plan.md), [Photo layout analysis](design/photo-layout-analysis.md) | Done |
| Visual Design | Create LED placement concept | P0 | Mark proposed LED zones: frame, fork, rear rack, basket, cat head, eyes, whiskers, tail, underglow, and optional wheels. | [LED zone plan](design/led-zone-plan.md), [Photo layout analysis](design/photo-layout-analysis.md) | Done |
| Electrical | Estimate LED count and power draw | P0 | Calculate max and typical current for selected LED type, brightness limits, and Pixelblaze output plan. Tentative decisions: 5 V primary system; 25-35% riding, 50-60% show, 10-15% reserve brightness caps. | [Power budget](../hardware/electrical/power-budget.md), [Photo layout analysis](design/photo-layout-analysis.md) | In Progress |
| Electrical | Select battery and protection | P0 | Choose dedicated LED battery voltage/capacity, fuse, switch, connectors, charging method, mounting direction, and runtime target. | Electrical | Design wiring harness | P0 | Document wire gauges, connector types, power injection points, strain relief, service disconnects, and reserved power/data interfaces for later head, tail, panels, and optional wheels. | [Power budget](../hardware/electrical/power-budget.md), [LED zone plan](design/led-zone-plan.md), [Wiring harness architecture](../hardware/electrical/wiring/wiring-harness-architecture.md) | In Progress |
